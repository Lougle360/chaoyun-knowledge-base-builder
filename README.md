# 超云的Ai之旅

个人博客 + FDE 获客站点：记录用 Cursor、Codex 等 AI 工具把想法落地的实战，并承接企业 / 个人的落地合作。

技术栈：**Astro + MDX**，中文界面。

## 本地预览

需 Node.js **≥ 22.12**。

```bash
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 `http://localhost:4321`）。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | 本地开发预览 |
| `npm run build` | 构建静态站点到 `dist/` |
| `npm run preview` | 预览构建结果 |

## 站点页面

| 路径 | 说明 |
| --- | --- |
| `/` | 首页：品牌 +「看作品 / 找我合作」双入口 |
| `/projects` | 项目案例（首批为占位，待确认后替换） |
| `/blog` | 文章列表（标签筛选 + 搜索） |
| `/blog/<slug>` | 文章详情（目录、上一篇/下一篇） |
| `/fde` | FDE 服务：范围、合作方式、流程、FAQ |
| `/about` | 关于（个人背景等待确认项用占位） |
| `/contact` | 联系 / 需求提交（前端表单 + 占位提交） |

## 内容怎么加

### 文章

在 `src/content/blog/` 新增 `.md` / `.mdx`：

```md
---
title: 文章标题
description: 一句话摘要
pubDate: 2026-11-21
tags:
  - Cursor
  - 复盘
---

正文……
```

### 案例

编辑 `src/data/projects.ts`，把占位案例换成真实项目（行业、问题、方案、成果、技术栈）。
